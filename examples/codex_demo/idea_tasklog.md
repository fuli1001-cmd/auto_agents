# Idea

Build a small Python CLI called `tasklog`.

Requirements:

- `python3 tasklog.py add "buy milk"` stores a task in a local JSON file
- `python3 tasklog.py list` shows pending tasks in a readable order
- `python3 tasklog.py done 1` marks the first task as completed
- Add a few unit tests under `tests/`
- Keep the project stdlib-only and avoid extra framework code
