# Bounded control v2 acceptance

The shared budget recorded **30 framework provider invocations**. It includes failed
attempts and protocol retries. No SDGP product code, database, account configuration,
or paid media operation was changed by these acceptance runs.

| Mode | Fixture and observed result |
| --- | --- |
| fix | A defective integer-doubling function was repaired, tested by real pytest, independently reviewed by the configured CLI, and committed locally. |
| run | Two dependent tasks built a Python HTTP server and counter frontend. Twelve server tests and seven browser/finalization tests passed. The browser helper exercised twelve assertions through actual Chromium CDP input and captured a PNG at count 3. Independent visual review and the original artifact check passed before delivery. |
| collab | The delivered doubling function was diagnosed, accepted with actual pytest evidence, and independently reviewed. The acceptance report was committed locally. This bounded native case exercised acceptance of existing correct code; delegated child recovery was exercised separately with fixture workers and real Git/pytest. |

The native tests exposed stage-purpose mistakes, harmless unittest flags rejected
by the old test-launch parser, a receipt-retry transaction gap, and verification
regenerating evidence after visual annotations. The generic fixes preserve exact
commands and distinguish frozen source from declared runtime outputs. Evidence
finalization does not rerun a mutating behavior test or edit verified source.

The configured `codex-fuli0110` account was used throughout. Confirmed-unavailable
fallback and unknown-outcome refusal are checked without spending additional real
provider calls. Provider filesystem boundaries protect shared content and metadata;
private CLI caches are collected after settled calls. After completion, the two
fixture business state directories measured approximately 352 KiB and 1.1 MiB.

Release checks also exercised the default CLI cutover, independent watcher,
SQLite migration, process confinement, public fault diagnostics, and native
credential-free Docker recovery. The full installed regression run passed
1,342 tests and 57 subtests; subsequent focused checks covered runtime-ignore
and Git porcelain column handling. Compilation and whitespace checks passed.

The native run fixture began before the mandatory prototype-approval and
structured-trace rules were added. Its disposable output declarations were
explicitly completed during acceptance, with no goal or call-budget change.
The final approval and trace rules are covered by behavior tests; this is not
claimed as another post-policy native model run. Provider resolution is covered
by domain and behavior tests, not an additional paid CLI acceptance.

SDGP state was rehearsed and then migrated locally to schema 2. Original goals,
the exact five-target fix command, seventy old call receipts, the original
25/15 node limits, workflow selection and private candidate deltas were retained.
Four existing private regressions passed in a separate auxiliary audit (21
executed tests, zero model/media calls). The fifth regression is explicitly
requested new implementation; it remains pending in the original fix. The
auxiliary checks are not substituted for the complete original command. Product
code, shared Git HEAD, provider configuration and application data were not
modified. Historical missing or conflicting proofs remain blocked with the
original database archive retained. This migration does not claim that the SDGP
video-generation business goal is complete.
